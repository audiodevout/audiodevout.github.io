6969osc

6969osc is a browser-based control surface for your phone: sixteen pads (momentary and toggle), a master fader, four XY pads, presets and randomize. A small Node.js server runs on your machine and serves the controller to any phone on the same network; touch input goes over WebSocket and is forwarded as OSC (UDP) to TouchDesigner (default 127.0.0.1:6969) or any OSC receiver. No app install. To run it, install Node.js 18+, start START.bat on Windows (run as administrator the first time so the firewall allows port 3000) or ./start.sh on macOS, then scan the QR code in the terminal with your phone on the same Wi‑Fi. SETUP.md covers TouchDesigner OSC In, config.json and troubleshooting.
